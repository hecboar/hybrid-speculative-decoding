# E3.2 — benchmark audit: interpretation (R2.6, EiC-6)

Falcon-H1-0.5B, greedy, val-test, max_new=40. **LATENCY IS NON-CANONICAL** (RTX
PRO 4500, not L4; mamba-ssm kernels absent → naive path). The transferable
results are the v1↔optimized RATIO, the per-phase breakdown, and c_eff.

## Measured (AR baseline = 23.1 tok/s)
| impl | k=1 | k=2 | k=4 |
|---|---|---|---|
| v1 (full recompute)   | 0.259× | 0.282× | 0.267× |
| optimized (prefix-KV reuse + cropped dual cache) | 0.278× | 0.210× | 0.198× |

Optimized per-phase (ms/emitted-token): overhead **58–75**, draft 32–99, verify
43–67, accept ~0.2. c_eff(measured) 0.75 / 0.91 / 1.81 for k=1/2/4.

## Reading
1. **Neither impl approaches the τ̄-based ceiling.** From E3.1 the S_theory ceiling
   for `component_only` on this hardware is ~0.87× (k=1). v1 and the optimized
   attempt both sit at ~0.20–0.28× — a ~3× gap that is pure **HF-stack / Python
   overhead**, NOT the drafting principle. This is the quantitative core of the
   "infrastructure bottleneck" thesis (R2 §2, EiC-6).
2. **The optimized attempt is overhead-bound, not compute-bound.** The dominant
   cost is `overhead` (58–75 ms/tok) — the Mamba hybrid-cache rollback
   (`crop` + re-advancing the dual draft/verify caches each round). It exceeds the
   prefix-reuse saving, so the "optimized" path only beats v1 at k=1 and is
   WORSE at k≥2. i.e. for this hybrid model, speculative rollback cannot be made
   cheap through the clean HF cache API alone; doing better needs cache-internal /
   kernel work, which HARD CONSTRAINT 1 forbids. That the honest attempt FAILS to
   beat v1 is itself evidence for the infrastructure bottleneck.
3. **Target narrative confirmed with a caveat:** the PLAN's hoped 0.34→0.7–0.85×
   is NOT reached on this un-accelerated stack; the residual gap is attributed to
   the HF software stack + missing SSM kernels, exactly as the infrastructure-
   bottleneck framing predicts. On an L4 with mamba kernels the SSM branch (and
   the rollback) would be far cheaper, lowering c_eff and the overhead together.
